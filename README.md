# Tessera

Downloads and update feed of Tessera, the bimover add-on for Archicad 28, 29 and 30 (macOS and Windows) that exports the 3D model in twelve formats from the Archicad Publisher.

- Product page and licences: https://www.bimover.ch/products/tessera
- Latest version: [Tessera-mac.zip](https://github.com/bimover/Tessera/releases/latest/download/Tessera-mac.zip), [Tessera-windows.zip](https://github.com/bimover/Tessera/releases/latest/download/Tessera-windows.zip)
- Update feed: `appcast.xml` (read via https://www.bimover.ch/updates/tessera/appcast.xml)

The source code is not public.
